## Проверка готового EXE

`python scripts/smoke_exe.py` и `python scripts/smoke_exe.py --legacy`: проверки готовой сборки на современном и старом локальных DOM-стендах.

Проверочный скрипт запустил готовый `BBBCompanion.exe` со временной папкой данных и локальной HTML-комнатой. Проверены:

1. Запуск локальной панели и нативного трея из EXE без консольного окна.
2. Автоматическое подключение по расписанию.
3. Запуск комплектного Chromium при запрете обращения к обычному браузерному кешу через переменную окружения.
4. Подтверждение режима слушателя.
5. Чтение волны сообщений и подтверждённая отправка ответа.
6. Показ и скрытие окна предмета через API и кнопки реальной панели без выхода из занятия и без потери режима слушателя.
7. Завершение через панельный API с кодом выхода 0.

Скрипт не подключается к настоящему BBB. Локальные журналы проверки находятся в `artifacts/frozen-smoke-*`.

Оба сценария выполнены для готового EXE 0.2.1: 15 подключений в двух предметах, по одному подтверждённому ответу на профиль. Тестовая волна отправляется после подтверждённого входа всех профилей, чтобы не попасть в пропускаемую начальную историю чата при холодном запуске. Дополнительно проверены реальные кнопки панели управления окнами предметов.
