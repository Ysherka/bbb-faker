# Публикация

В Git хранятся исходники, тесты, документация и вымышленный пример настроек. Локальные настройки, базы, журналы, диагностика, сборки и окружение исключены через `.gitignore`.

Перед первым push проверьте `git diff --cached` и `git ls-files`. В списке не должно быть папок `data`, `dist`, `artifacts`, файлов `config.json`, SQLite-баз или снимков реальных занятий.

## Готовая Windows-сборка

ZIP со сборкой размещается в GitHub Releases, отдельно от исходников. Репозиторий содержит настройки GitHub Actions для запуска локальных тестов на Windows.

Полная сборка:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build.ps1 -Release 0.2.1
```

Сборщик создаёт новый каталог и отказывается перезаписывать каталог, содержащий пользовательскую папку `data`. Для повторной сборки после использования выберите другой идентификатор, например `0.2.1-r1`.

В релизный ZIP должны входить EXE, комплектные библиотеки, Chromium, инструкция и вымышленный пример настроек. Не архивируйте использованную папку приложения целиком: в ней могла появиться папка `data` с настоящими участниками и текстом чата.

Для безопасной упаковки уже использованной сборки:

```powershell
.\.venv\Scripts\python.exe scripts\package_release.py
```

Скрипт берёт только EXE, `_internal` и `browsers`, добавляет актуальные публичные README и пример настроек из исходников и создаёт ZIP с SHA-256 в `dist/github`. Папка пользовательских данных в архив не включается.

## Авторизация GitHub CLI

```powershell
gh auth login --hostname github.com --web --git-protocol https
```

Вход выполняется пользователем в браузере. Токены не нужно записывать в файлы проекта или передавать в чат.
